# ASA 1.1.4 Release Plan

> **For agentic workers:** Use the executing-plans workflow to complete this release task-by-task.

**Goal:** Publish stable ASA 1.1.4 with a newly built and release-signed arm64-v8a APK.

**Architecture:** Keep the existing Android application ID and release signing certificate. Bump the public app version to `1.1.4+5`, inject `APP_VERSION=1.1.4` and a fresh UTC `BUILD_TIME`, build a single-arm64 APK, then create GitHub release `v1.1.4` and upload the artifact.

**Tech Stack:** Flutter/Dart, Android Gradle, Kotlin, GitHub Releases REST API, macOS Keychain.

## Global Constraints

- Do not use or publish a debug-signed APK.
- Do not print or commit passwords, tokens, keystores, or private endpoint configuration.
- Preserve application ID `com.example.asa` and release certificate.
- Android build number must be greater than the previous `versionCode=4`.
- Verify package metadata, ABI, signature, and SHA-256 before upload.
- Create a stable, non-draft GitHub release `v1.1.4`.

### Task 1: Commit notification setup fix

- Verify focused setup and notification tests.
- Commit the existing fix with a conventional subject: `fix(notifications): initialize service before permission request`.

### Task 2: Bump version

- Change `pubspec.yaml` from `1.1.3+4` to `1.1.4+5`.
- Change the `VersionService` fallback `APP_VERSION` from `1.1.3` to `1.1.4`.
- Commit as `chore: bump version to 1.1.4+5`.

### Task 3: Build and verify APK

- Build with `--target-platform android-arm64 --split-per-abi --release` and dart defines `APP_VERSION=1.1.4` and fresh UTC `BUILD_TIME`.
- Use the owner-only keystore configuration and Keychain password; fail if Gradle falls back to debug signing.
- Copy to `Asa-v1.1.4-arm64-v8a.apk`.
- Verify `versionName=1.1.4`, `versionCode=5`, package `com.example.asa`, only `arm64-v8a`, release certificate, and SHA-256.

### Task 4: Publish GitHub release

- Create stable GitHub release `v1.1.4` with user-facing notes covering the notification setup fix and prior 1.1.3 functionality.
- Upload only `Asa-v1.1.4-arm64-v8a.apk`.
- Re-fetch the release and verify tag, stable/draft flags, asset metadata, digest, and release asset name.
