Политика конфиденциальности ASA

Дата вступления в силу: 11 августа 2026 г.

Настоящая политика описывает, как приложение ASA обрабатывает данные пользователей. ASA — офлайн-планировщик задач для Android и других поддерживаемых платформ. Разработчик: Sabir Dzhabrailov. Контакт: SabirDzhabrailov.111@mail.ru.

1. Какие данные обрабатывает приложение

Пользователь может самостоятельно создавать в приложении задачи, папки, описания, ссылки, изображения, файлы, настройки времени и напоминаний. Эти данные нужны для работы функций планировщика.

При использовании календаря приложение может читать доступные календари и создавать, обновлять или удалять события, связанные с задачами. Это происходит только после предоставления разрешения и действия пользователя.

Для виджетов Android приложение сохраняет на устройстве ограниченные данные, необходимые для отображения активных задач, серии и выбранной папки.

2. Где хранятся данные

По умолчанию задачи, настройки, ссылки и локальные вложения хранятся на устройстве пользователя в локальном хранилище приложения. ASA не требует регистрации и не создает облачный аккаунт пользователя.

Пользовательские резервные копии создаются по запросу пользователя и могут быть переданы через системное меню Android выбранному пользователем приложению. Копии в выбранном месте назначения регулируются политиками соответствующего приложения.

3. Синхронизация между устройствами

Синхронизация отключена по умолчанию и включается пользователем отдельно. Она работает между выбранными устройствами в одной локальной сети через локальное сетевое соединение. При заданном общем секрете данные синхронизации шифруются с использованием AES-256-GCM. Без заданного секрета передача не должна рассматриваться как конфиденциальный канал.

ASA не отправляет данные задач в облачный сервер ASA. Пользователь сам выбирает, включать ли синхронизацию и с каким устройством обмениваться данными.

4. Сетевые запросы

Приложение может обращаться к публичному GitHub API для проверки доступности обновлений и отображения истории релизов. В эти запросы не включаются задачи, файлы, фотографии, календарные события или другие пользовательские данные.

В версиях ASA, собранных с настроенным публичным HTTPS endpoint диагностики, по явному действию пользователя приложение может отправить диагностический отчёт на сервер разработчика. Если endpoint не настроен, отправка отключена. Отчёт содержит версию приложения, платформу, модель устройства, случайный идентификатор установки и ограниченный буфер технических логов. Перед отправкой приложение удаляет или маскирует известные секреты, токены, пароли, email-адреса, IP-адреса, URL и локальные пути. Задачи, описания, вложения, резервные копии, содержимое буфера обмена и синхронизационные секреты в отчёт не включаются. Отчёты хранятся по умолчанию 30 дней в инфраструктуре Vercel и Neon, после чего удаляются.

5. Уведомления

Напоминания о задачах являются локальными уведомлениями, планируемыми на устройстве. ASA не использует удаленный push-сервер для доставки этих напоминаний.

6. Передача третьим лицам

ASA не продает и не передает пользовательские данные третьим лицам для рекламы. Передача данных может происходить только по инициативе пользователя: при экспорте через системное меню, выборе файла/ссылки во внешнем приложении, включении локальной синхронизации с выбранным устройством или отправке диагностического отчёта разработчику. Диагностические отчёты обрабатываются Vercel как хостингом серверной функции и Neon как поставщиком базы данных, в соответствии с их условиями и политиками конфиденциальности. Регион обработки зависит от выбранной конфигурации этих сервисов.

7. Удаление данных

Пользователь может удалять задачи и настройки средствами приложения, удалять локальные файлы и вложения, а также удалить все данные приложения средствами операционной системы Android. Экспортированные копии нужно удалять отдельно из места, куда они были сохранены или переданы. Для запроса удаления диагностического отчёта укажите его номер в письме разработчику: SabirDzhabrailov.111@mail.ru.

8. Дети

ASA не предназначено для сбора данных детей и не содержит регистрации или целевой рекламы. Приложение является инструментом общего планирования задач.

9. Изменения политики

При изменении функций или способов обработки данных эта политика может быть обновлена. Дата новой редакции будет указана в начале страницы. Существенные изменения будут отражены в описании или обновлении приложения.
