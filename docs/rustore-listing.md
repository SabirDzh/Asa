## 1. Основные поля карточки

### Название

`ASA`

### Краткое описание

> Планировщик задач, таймеры, папки и офлайн-синхронизация.

Количество символов: 59.

### Подробное описание

> ASA — простой планировщик задач для тех, кто хочет держать дела под контролем без обязательной регистрации и облачного аккаунта.
>
> Возможности:
> - создавайте задачи и организуйте их по папкам;
> - задавайте периоды выполнения и запускайте таймер;
> - отмечайте задачи выполненными и отслеживайте ежедневную серию;
> - добавляйте описания, ссылки, изображения и файлы;
> - планируйте задачи в календаре устройства;
> - получайте локальные напоминания о начале задач и сроках;
> - используйте виджеты Android для быстрого доступа;
> - экспортируйте и импортируйте резервные копии;
> - при необходимости синхронизируйте данные между устройствами в одной локальной сети.
>
> ASA работает в первую очередь локально: задачи и настройки сохраняются на устройстве. Облачная учетная запись не требуется. Локальная синхронизация включается пользователем отдельно и выполняется между выбранными устройствами в одной сети. Экспорт передает данные только в приложение, которое пользователь выберет через системное меню Android.
>
> Приложение не содержит рекламы и не требует регистрации. Поддерживаются русский и английский языки, светлая и темная темы, масштаб интерфейса и настройка уведомлений.
>
> Для работы отдельных функций могут потребоваться разрешения на уведомления, календарь, выбор файлов и изображений, работу фоновых напоминаний и отображение виджетов. Разрешения запрашиваются по мере необходимости и управляются пользователем в системных настройках.

Количество символов: менее 4000.

## 2. Безопасность данных — фактическая декларация

Заполняйте раздел на основании поведения текущей Android-сборки. В приложении нет регистрации, пользовательского аккаунта, рекламы и встроенной аналитики.

| Категория | Что происходит | Статус для декларации |
|---|---|---|
| Имя/текстовые данные | Названия задач, описания, названия папок, заметки | Пользователь вводит сам; хранится локально. Передается только при явно включенной LAN-синхронизации или экспорте через Share |
| Файлы и документы | Вложения, выбранные пользователем | Копируются в локальное хранилище приложения. Не отправляются автоматически; могут быть переданы выбранному пользователем приложению через системный Share, а также отправлены на выбранное устройство при LAN-синхронизации |
| Фото и видео | Выбранные изображения для вложений/аватара | Хранятся локально в приложении; могут быть переданы выбранному пользователем приложению через Share или выбранному устройству при LAN-синхронизации |
| События календаря | Данные события, связанные с задачей | Читаются/создаются в календаре устройства только после действия пользователя; на сервер ASA не отправляются |
| Идентификатор устройства для синхронизации | Локальный стабильный ID устройства и отображаемое имя | Используется при включенной синхронизации в локальной сети и виден обнаруженным устройствам; в облако ASA не отправляется |
| Диагностические данные | В версиях с настроенным endpoint: ограниченный буфер технических логов и безопасные метаданные устройства | Передаются только после явного подтверждения пользователя на HTTPS endpoint разработчика; известные секреты, задачи, вложения и резервные копии не включаются; действует ограниченный срок хранения. В APK без `DIAGNOSTICS_ENDPOINT` отправка отключена |
| Сетевые данные | Запрос метаданных обновлений к GitHub | В запрос не включаются задачи и файлы пользователя, но GitHub как сетевой сервис получает стандартные технические данные запроса, например IP-адрес и User-Agent |
| Уведомления | Локальные напоминания о задачах | Обрабатываются на устройстве; удаленный push-сервер ASA не используется |

### Итоговые ответы для полей формы

- **Собираются ли данные приложением:** ASA не ведет облачный сбор пользовательских данных; пользовательские данные создаются и по умолчанию хранятся локально.
- **Передаются ли данные третьим сторонам:** в версиях с настроенным endpoint — да, только по явному действию пользователя: выбранному приложению через системный экспорт/Share, выбранному устройству в локальной сети или серверу диагностики разработчика. Диагностический отчёт проходит через Vercel и хранится в Neon по умолчанию не более 30 дней. В APK без `DIAGNOSTICS_ENDPOINT` отправка отключена. Запрос GitHub содержит только запрос публичных релизов, но сопровождается стандартными техническими данными сетевого соединения.
- **Есть ли аккаунты:** нет.
- **Есть ли реклама:** нет.
- **Есть ли аналитика или трекинг:** нет в текущей сборке.
- **Есть ли автоматическая отправка диагностических логов:** нет. Пользователь сам запускает отправку и подтверждает её в диалоге; отправляется только редактированный технический отчёт.
- **Можно ли удалить данные:** да, пользователь может удалить задачи, настройки, вложения и данные приложения средствами приложения/Android; экспортированные копии удаляются отдельно пользователем из места назначения. Диагностический отчёт, если он был отправлен в версии с endpoint, можно удалить из админ-панели или запросить удаление по его номеру через email разработчика.
- **Шифруется ли передача синхронизации:** при заданном секрете синхронизация использует AES-256-GCM; без секрета приложение не следует считать защищенным каналом, поэтому секрет рекомендуется включать перед синхронизацией.

> Если изменятся endpoint, срок хранения, состав отчёта, авторизация или способы обработки данных, эту декларацию и политику конфиденциальности нужно обновить до публикации новой версии.
